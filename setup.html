🔑 푸시 키 생성기

VAPID 키와 관리자 키를 이 브라우저 안에서만 만듭니다. 서버로 전송되지 않습니다.
한 번 만들어 등록하면 다시 만들 필요가 없습니다. (다시 만들면 기존 구독자가 모두 재구독해야 합니다)

VAPID_PUBLIC_KEY → config.js + Supabase Secret
VAPID_PRIVATE_KEY → Supabase Secret에만
ADMIN_KEY → Supabase Secret + 관리자 로그인용

⚠️ 개인키(PRIVATE)와 관리자 키는 GitHub 등 공개된 곳에 올리지 마세요. 메모장에 따로 보관하세요.
